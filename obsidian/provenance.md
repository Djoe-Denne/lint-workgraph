# Source and public-export provenance

The pipeline was exported from revision
`c4bba486291edd63dabafd5b5235c2d1ba628fa0` of its original host workspace.
That is a provenance reference, not an import of the host's Git history.

The user explicitly authorized a new public `Djoe-Denne/lint-workgraph`
repository and chose to retain the original scripts provisionally.

## Public content

- Curated Python implementation and dependency pin.
- Reproducible tests and invented/synthetic source fixtures.
- Standalone English guides and contracts.
- This new linked Markdown vault.

## Excluded content

- Original application implementation and private raw analysis/MCP captures.
- Real campaign runtime outputs, temporary scripts, logs and environment dumps.
- Original wiki, manifests, agent sessions and instructions.
- Credentials, private URLs, personal absolute paths and generated Obsidian state.

Necessary compatibility-profile identifiers are explicitly documented, not
represented as generic support. Historical campaign figures in [[history]] are
aggregate observations, not bundled real data.

The publisher must inspect the actual public candidate set before the first
push. No source-root software license was transferred or invented; license
selection remains open.
